## English

### Overview

**CodeStudioEditor** is a lightweight, modern and fast code editor built for Windows. It gives you everything you need to write code — and nothing you don't. Optimized to run smoothly even on modest hardware (4 GB RAM), it's portable by design and completely free.

### Features

- **Full file manager** — Create, rename, delete, duplicate and copy-paste files and folders without leaving the editor.
- **Search & replace** — Find anything instantly with `Ctrl+F`, with full regex support.
- **Syntax highlighting & error detection** — Clear, accurate coloring and inline error markers.
- **Multiple tabs & command palette** — Work on several files at once and reach any action with `Ctrl+Shift+P`.
- **8 built-in themes + custom themes** — Pick a palette or create your own.
- **Optimized for 4 GB RAM** — Lightweight by design, smooth even on modest hardware.

### Installation

1. **Download the installer** — Grab the latest `.exe` from the [Releases](https://github.com/alexis-dpt/codestudioeditor/releases) page.
2. **Install and launch** — Run the setup, launch the app and you're in.
3. **Start coding** — Open a folder or a file and you're ready to go.

> **Prefer portable?** Unzip the installer archive to run CodeStudioEditor from anywhere, including a USB drive — no installation required.

### System Requirements

| Requirement      | Details                       |
| ---------------- | ----------------------------- |
| Operating system | Windows 10 / 11               |
| Browser engine   | Microsoft Edge or Chrome      |
| Memory           | 4 GB RAM minimum              |
| Disk space       | ~100 MB free space            |

### Tech Stack

- HTML5 / CSS3 / vanilla JavaScript
- No framework, no external dependency
- Dark-mode-first, responsive and accessible design
